# **# ✈️ Airline Data Analysis**



#### **## 📌 Project Overview**

This project focuses on analyzing airline ticket pricing data to understand flight price patterns, airline performance, and the factors that influence ticket prices.



The analysis explores how ticket prices vary across different airlines, travel classes, number of stops, flight durations, and days left before departure. An interactive Power BI dashboard is created to present key insights through visualizations and KPIs.



#### \## 🎯 Project Objectives

\- Analyze average ticket prices across different airlines.

\- Compare ticket prices for Economy and Business classes.

\- Understand the impact of stops on ticket prices.

\- Explore the relationship between days left before departure and ticket prices.

\- Analyze flight distribution across airlines.

\- Build an interactive dashboard for better data visualization.



#### **## 🛠️ Tools \& Technologies**

\- **Python:** Data loading and analysis

\- **Pandas:** Data manipulation

\- **MySQL:** Data storage and SQL queries

\- **Power BI**: Interactive dashboard and visualization

\- **Jupyter Notebook:** Python environment



#### **## 📂 Dataset Information**

The dataset contains approximately \*\*300,153 flight records\*\* with 12 columns, including:



\- Airline

\- Flight

\- Source City

\- Destination City

\- Departure Time

\- Arrival Time

\- Stops

\- Class

\- Duration

\- Days Left

\- Price



#### **## 🔍 Project Workflow**

1\. Imported and explored the airline dataset using Python.

2\. Connected Python with MySQL.

3\. Stored 300,153 records in the MySQL database.

4\. Performed SQL queries to analyze flight and pricing information.

5\. Connected the MySQL database to Power BI.

6\. Created an interactive dashboard with KPIs, charts, and slicers.



#### **## 📊 Power BI Dashboard**

**The dashboard includes:**

\- Total Flights

\- Total Airlines

\- Average Ticket Price

\- Average Flight Duration

\- Airline-wise Average Ticket Price

\- Class-wise Average Ticket Price

\- Average Ticket Price by Stops

\- Days Left vs Average Ticket Price

\- Interactive filters for Airline, Source City, Destination City, Class, and Stops
